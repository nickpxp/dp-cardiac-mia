# Protecting healthcare machine learning from membership inference

[![Paper DOI](https://img.shields.io/badge/DOI-10.48009%2F1__iis__2026__113-blue.svg)](https://doi.org/10.48009/1_iis_2026_113)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Code, data and results for:

> Pierrelouis, N., & Liu, X. (2026). Protecting healthcare machine learning from membership inference: An evaluation of differential privacy. *Issues in Information Systems*, 27(1), 181–195. https://doi.org/10.48009/1_iis_2026_113

The paper evaluates central differential privacy on a Gaussian Naive Bayes classifier for atrial-fibrillation detection, compares the Laplace and Gaussian mechanisms across seven privacy budgets, measures black-box membership inference, compares three model families at ε = 1.0, and shows that where the noise is placed (sufficient statistics vs. input features) decides whether the model is usable. The procedural contribution is the Investigation–Implementation–Assessment (IIA) framework.

Every number in Tables 1–4 is regenerated by `tools/run_paper_numbers.py` from the CSVs in `results/`, and every CSV is regenerated from `data/ddata.csv` by the runners in `experiments/`.

## Headline results

| | Laplace (ε-DP) | Gaussian ((ε, δ)-DP) |
|---|---|---|
| NB accuracy at ε = 1.0 | 0.7554 ± 0.0006 | 0.7421 ± 0.0170 |
| Utility loss vs. 0.7555 baseline | 0.01% | 1.77% |
| MIA success at ε = 1.0 | 0.509 | 0.501 |
| Paired t-test at ε = 1.0 (n = 5, matched seeds) | t = 1.598, p = 0.185 | |

Feature-wise (input) perturbation with the same model, data and budgets pins accuracy at the majority class (0.6251, F1 = 0) for every ε ≤ 3. Central placement recovers the non-private ceiling by ε = 1.0.

## Method in one paragraph

Features are min-max scaled to [0, 1] with bounds from the training split, treated as public. Per class the model releases one count, one sum per feature and one sum of squares per feature (k(1 + 2d) = 30 statistics), each with sensitivity 1 (Vaidya, Shafiq, Basu & Hong, 2013). The budget is split equally by sequential composition, ε_q = ε/30 and δ_q = δ/30, with δ = 10⁻⁵. The Laplace arm adds Laplace(0, 1/ε_q); the Gaussian arm adds N(0, σ²) with σ = √(2 ln(1.25/δ_q))/ε_q. Means and variances are rebuilt from the noisy statistics (variance floored at 10⁻³) and the classifier is post-processing. Both arms share one code path, seeds 42–46, and differ only in the noise distribution. Membership inference is the black-box rule-based attack (member iff classified correctly; the 0-1 loss thresholded at the decision boundary, as shipped in ART as `MembershipInferenceBlackBoxRuleBased`), scored as balanced accuracy on 2,000 members and 2,000 non-members. Random forest uses diffprivlib's central-DP forest; logistic regression uses output perturbation (Chaudhuri, Monteleoni & Sarwate, 2011) with λ = 10⁻³.

## Reproducing

```bash
git clone https://github.com/nickpxp/dp-cardiac-mia
cd dp-cardiac-mia
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
pip install -e .

python experiments/run_all.py        # ~10 minutes on a laptop
python tools/run_paper_numbers.py    # tables only, no training
python -m pytest tests               # 14 tests, ~20 s
```

Each runner can be run alone. All are seeded and deterministic given the pinned library versions; the regression test in `tests/test_paper_numbers.py` checks the Table 2 cells at ε = 1.0 against the committed data.

### Environment

The paper's numbers were produced with Python 3.12.5, scikit-learn 1.8, NumPy 2.4.6, pandas 3.0.3 and diffprivlib 0.6.6, which `requirements.txt` pins. Two things to know:

- **diffprivlib 0.6.6 does not import against scikit-learn ≥ 1.9** (`sklearn.tree._tree` dropped the `DOUBLE`/`DTYPE` aliases). Stay on scikit-learn 1.8, or patch the two names to `np.float64`/`np.float32` in `diffprivlib/models/forest.py`.
- **The non-private random-forest baseline moves with the scikit-learn version** even at a fixed `random_state`: 0.7568 in the paper, 0.7571 on a later 1.8 run, 0.7541 on 1.9.1. The DP forest (0.7536) and every NB and LR number are identical across versions. Only the RF utility-loss cell in Table 3 is affected (0.41% in the paper; 0.07% on 1.9.1).

## Data

`data/ddata.csv` is synthetic. A 20,000-row source table was drawn from a shared-latent generator in which every feature is a noisy function of a hidden AF propensity (so no feature copies the label), audited for leakage (no feature with |r| > 0.9 or single-feature accuracy > 0.9), then CTGAN (300 epochs) was fitted on it and 100,000 rows sampled. Prevalence is 0.372; the strongest feature–label correlation is 0.44 (ECG); the majority-class accuracy is 0.628 and a full-feature random forest reaches 0.752. CTGAN is unseeded, so `tools/generate_data.py --regenerate` gives a new draw with new numbers; the committed file is the one the paper used. No real patient data was involved.

| Item | Paper | This repository |

| Tables 1, 2, 4; NB and LR rows of Table 3 | as printed | identical to four decimals |
| Table 3, RF utility loss | 0.41% (non-private RF 0.7568) | 0.07% on scikit-learn 1.9.1, 0.45% on a later 1.8 run; DP RF accuracy 0.7536 in all cases |

| Sensitivity | Δf described as L1 in one place and L2 in another | each statistic is released as a scalar, so L1 = L2 = 1 |
| Timing trials | 50 | 50 (`N_TIMING_TRIALS`); timing is hardware-dependent and recorded with its environment |
